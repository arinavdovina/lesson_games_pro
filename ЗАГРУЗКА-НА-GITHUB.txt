ПОЛНЫЙ НАБОР ФАЙЛОВ САЙТА

В архиве находится папка lesson-play. Распакуйте её на компьютере.
В корень репозитория должны попасть файлы и папки ИЗНУТРИ lesson-play.

Структура:
index.html
style.css
app.js
game.js
catalog.js
assets-data.js
README.md
.nojekyll
originals/ — 14 исходных HTML-игр
assets/
    part-1/ — 60 изображений
    part-2/ — 60 изображений
    part-3/ — 55 изображений

Все ссылки на изображения уже исправлены. Имена файлов и папок менять не нужно.

GitHub ограничивает загрузку через браузер 100 файлами за один приём, включая файлы во вложенных папках. Поэтому разделение assets не позволяет загрузить весь сайт одним перетаскиванием.

Чтобы загрузить через браузер:
1. В корень репозитория загрузите файлы сайта и папку originals, пока без assets. Нажмите Commit changes.
2. Создайте assets: Add file → Create new file → имя assets/README.txt → текст «Изображения сайта» → Commit changes.
3. Откройте assets на GitHub. Через Add file → Upload files перетащите целиком подпапку part-1 с компьютера. Нажмите Commit changes.
4. Снова в assets загрузите целиком part-2, затем таким же способом part-3. После каждой загрузки нажмите Commit changes.

На GitHub должны сохраниться пути assets/part-1/имя.webp и аналогичные для part-2 и part-3.
Не загружайте ZIP вместо файлов сайта.

Если хотите загрузить весь набор за один приём, используйте GitHub Desktop.

После загрузки: Settings → Pages → Deploy from a branch → main → / (root) → Save.
